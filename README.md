# Server Prune

A lightweight Windows desktop application for viewing, selecting, and cleaning up Discord servers through a clean, minimal interface.

## Features

- Compact server list with expandable details
- Search by server name or ID
- Select or deselect multiple servers
- Filter by category and sort by name
- View server icons, IDs, owner status, and categories
- Export server lists to JSON or CSV
- Preview selected servers before cleanup
- Remember window size and preferences

## Tech Stack

- Python
- HTML, CSS, JavaScript
- pywebview

## Status

In development

## Security

Designed to minimize unnecessary API requests and protect sensitive credentials. Authentication and cleanup operations must respect Discord's supported API capabilities and policies.
